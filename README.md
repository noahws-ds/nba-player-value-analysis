# NBA Player Value Analysis (2022-23 Season)

## Overview 
I had a question as someone who enjoys the NBA: Which players are steals compared to their salaries? This project was created to answer this question by analyzing the 2022-23 Season using a custom Value Score by taking a player's Player Efficiency Rating (PER) and dividing it by their adjusted salary. The higher the score, the more value the player provides to their team relative to what they're being paid. 

## Tools Used 
- Python, pandas, matplotlib, seaborn, Jupyter Notebook 

## Key Findings 
- Rookies and minimum contract players dominated in the Value Score ranking
- Players like Russell Westbrook and Klay Thompson ranked as the least efficient relative to their contract
- Players were filtered to 65+ games played to match NBA award eligibility standards


## How to Run
1. Clone the repository
2. Add `nba_stats_salaries.csv` to the project folder
3. Open `nba_salary_value_2022-23.ipynb` in Jupyter Notebook
4. Run Kernel → Restart & Run All
